Politique de confidentialité — FolioFix

Dernière mise à jour : 21 août 2026
Éditeur : Yusuf Celik
Application : FolioFix (com.yusufcelik.FolioFix) pour macOS

Résumé

FolioFix fonctionne entièrement en local sur votre Mac. Nous ne collectons aucune donnée personnelle.

Données collectées

Aucune. Pas de compte, pas d’analytics, pas de publicité, pas de télémétrie.

Fichiers PDF

Les PDF que vous ouvrez, modifiez ou enregistrez restent sur votre appareil. Ils ne sont pas envoyés à un serveur.

Signature enregistrée

Si vous créez une signature, elle est stockée localement dans le dossier Support d’application de FolioFix sur votre Mac.

OCR

La reconnaissance de texte utilise les technologies Vision d’Apple sur l’appareil. Aucune image n’est transmise à l’éditeur de l’app.
